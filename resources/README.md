# resources/ —— 外部资源的本地脚本

这里的每个子目录都是某类**外部资源（command 形态）**的本地实现：启明把命令模板挂成
模型可调用的工具，脚本从 stdin 读 JSON、往 stdout 打一行 JSON 结果。

| 目录 | 资源 | 是否需要额外安装 |
|---|---|---|
| `browser-use/` | 浏览器操作：自然语言驱动浏览器（`browser_task`） | 需要，`bash resources/browser-use/install.sh`（会建独立 venv） |
| `proxy/` | 代理访问：走本机代理取被墙资源（GitHub 等） | 不需要额外依赖（只用 Python 标准库），但需要一个可用的本地代理端口 |

两处都**不是必装**：不装，对应的工具就在界面上显示"未连接"，其余功能不受影响。

## 自定义

想加自己的外部资源，不必动这里 —— 「设置 → 外部资源」里直接添加三种形态之一：

- `mcp`：填一个 MCP 服务器的启动命令；
- `http`：填 Base URL + 若干动作（方法 / 路径 / 参数）；
- `command`：填一条命令模板（stdin 进 JSON、stdout 出 JSON），本目录就是两个 command 资源的样例。

资源的提示词与每个工具的描述都能在界面上直接改（「设置 → 提示词」里也是同一条记录）。
